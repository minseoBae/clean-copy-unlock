수집하는 정보

Clean Copy Unlock은 어떠한 개인정보, 방문 기록, 검색 기록, 페이지 콘텐츠도 수집·저장·전송하지 않습니다. 이 확장 프로그램은 사용자의 기기 밖으로 어떤 데이터도 내보내지 않으며, 원격 서버와 통신하지 않습니다.

사용하는 권한

storage: 툴바 팝업의 ON/OFF 토글 상태(enabled 값) 하나만 브라우저 로컬 저장소(chrome.storage.local)에 저장하기 위해 사용합니다. 이 값은 사용자의 브라우저 안에만 저장되며, 외부로 전송되지 않습니다.

이 외의 권한(호스트 권한 기반 방문 기록 수집, 분석 도구, 광고 SDK 등)은 전혀 사용하지 않습니다.

동작 방식

콘텐츠 스크립트는 각 웹페이지 안에서 로컬로 실행되며, 우클릭 메뉴·텍스트 선택·복사/잘라내기·드래그·일부 단축키(Ctrl/Cmd+C, A, X)에 대한 사이트의 차단 로직을 무력화하는 역할만 합니다. 페이지 콘텐츠를 읽어 외부로 전송하거나, 다른 웹사이트·서버와 통신하는 코드는 포함되어 있지 않습니다.

제3자 공유

수집하는 데이터가 없으므로 제3자와 공유하거나 판매하는 데이터도 없습니다.

English

Information We Collect

Clean Copy Unlock does not collect, store, or transmit any personal information, browsing history, search history, or page content. The extension sends no data off the user's device and does not communicate with any remote server.

Permissions Used

storage: Used only to persist a single ON/OFF toggle value (enabled) in the browser's local storage (chrome.storage.local). This value stays on the user's device and is never transmitted anywhere.

No other permissions (host-permission-based history collection, analytics, ad SDKs, etc.) are used.

How It Works

The content script runs locally on each page and only neutralizes a site's blocking logic for the context menu, text selection, copy/cut, drag, and a small set of keyboard shortcuts (Ctrl/Cmd+C, A, X). It contains no code that reads page content and sends it elsewhere, and no code that communicates with any website or server.

Third-Party Sharing

Since no data is collected, none is shared with or sold to any third party.

Changes to This Policy

Any changes to this policy will be reflected in this document and in the repository's commit history.
